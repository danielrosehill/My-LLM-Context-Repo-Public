## Operating Systems and Software Preferences

### Operating Systems
Daniel's primary operating systems are OpenSUSE Linux Tumbleweed on his desktop and Android for his phone.

### Software Preferences
Daniel prioritizes software that is offered as a service with a robust and reliable web user interface (UI) and an Android client. He prefers not to self-host services if possible and often finds Linux software lacking. For applications like note-taking and business-related tools, web and Android accessibility as a key advantage.
